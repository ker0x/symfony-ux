# Symfony UX Share Link

**EXPERIMENTAL** This component is currently experimental and is
likely to change, or even change drastically.

Symfony UX Share Link generates share links for Email (`mailto:`),
Facebook, X (Twitter), LinkedIn, Threads, WhatsApp, Telegram, Reddit,
Pinterest, Bluesky and Mastodon, so you can let users share any page
or piece of content on the social platform of their choice with a
single Twig function call.
It is part of [the Symfony UX initiative](https://symfony.com/ux).

**This repository is a READ-ONLY sub-tree split**. See
https://github.com/symfony/ux to create issues or submit pull requests.
